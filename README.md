This is a RGB to HEX converter. It takes RGB values as input and converts them to their corresponding HEX color code. The script is designed to be simple and easy to use, allowing users to quickly convert colors for web design, graphic design, or any other application that requires color representation in HEX format.

This project is still in development and isn't complete, and I plan to add more features in the future, such as the ability to convert HEX to RGB
